# Spectra Analyzer 0.1.5

This release improves the existing Paste Format workflow.

- Remember selected formatting options across application restarts.
- Apply the selected options to the current graph with one click, or choose exact
  graph targets, including multiple graphs within the same dataset.
- Select formatting options separately. After pasting, adjust the selection;
  deselected options restore each target's own original values.
- Undo the whole paste batch together, with guards for subsequent edits and drafts.
- Open formatting for a source-linked Analysis graph through its source graph.

Windows downloads include a standalone installer and portable ZIP. The installer
and adjacent SHA-256 file support the application's existing update channel.
Use Help > Check for Updates to find this release through the existing update
channel. The application and installer remain unsigned, as in previous releases.

Publication requires the exact source commit to pass the complete Windows suite
on GitHub before a clean release build, source and frozen diagnostics,
production executable startup/close smoke, and isolated installer lifecycle
validation. Hidden startup smoke does not establish visual or high-DPI correctness.
